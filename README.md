# EALabtp sl entry · Candle Pattern Lab

เว็บ dashboard สำหรับวาดหรืออธิบายแพตเทิร์นแท่งเทียน แล้วให้ Gemini สรุป HLOC และสร้างรูปตัวอย่างขาขึ้น/ขาลง ส่วนกฎตรวจจับ JavaScript สร้างจากแม่แบบอย่างกระชับใน server พัฒนาอยู่ใน repository Candle Pattern Lab

## เปิดใช้งานในเครื่อง

1. ติดตั้ง Node.js 18 ขึ้นไป
2. รัน **npm install**
3. คัดลอก **.env.example** เป็น **.env** แล้วใส่ Gemini API key
4. รัน **npm start** แล้วเปิด http://localhost:3000

เครื่องมือวาด จุดปรับรูปทรง คำอธิบายแพตเทิร์น undo/redo และคลังแพตเทิร์นทำงานในเบราว์เซอร์ การสร้าง logic ด้วย AI ใช้ **GEMINI_API_KEY** ที่ฝั่ง server เท่านั้น โดยไม่ส่ง key ไปยังหน้าเว็บ เปลี่ยนโมเดลได้ด้วย **GEMINI_MODEL**

## Deploy

Deploy เป็น Node web service โดยใช้ root directory ที่ repository root, build command **npm install** และ start command **npm start** จากนั้นเพิ่ม **GEMINI_API_KEY** ใน Environment ของผู้ให้บริการ แอปจำกัดคำขอ AI ต่อ IP ในแต่ละนาที

## ฟังก์ชัน

- วาดแท่งขึ้นและแท่งลงได้สูงสุด 12 แท่ง โดยจัดแท่งแรกไว้กลางกราฟตั้งแต่เริ่ม
- ลากเส้นทั่วไป วาดกรอบสี่เหลี่ยม และวาดเส้นหักหลายจุดเพื่อระบุทิศทางราคาที่คาดหลังแพตเทิร์นเกิด โดยมีเส้นกำกับรวมได้สูงสุด 40 เส้น
- วาง Entry / TP / SL อย่างละหนึ่งเส้น ระบบจะแทนที่เส้นเดิมเมื่อวางระดับชนิดเดียวกันอีกครั้ง
- เลือกแล้วลากเส้น กรอบ หรือจุดหักเพื่อแก้ไข หรือลบด้วยเครื่องมือลบ; Entry / TP / SL มีได้อย่างละหนึ่งเส้นและแทนที่เส้นเดิมเมื่อวางซ้ำ
- ลากไส้เทียนเพื่อแก้ High หรือ Low, ลากจุดจับเพื่อแก้ Open / Close และลากตัวแท่งเพื่อย้ายทั้งแท่ง โดยกราฟจะไม่เลื่อนขณะปรับแท่ง
- แสดงสัดส่วน HLOC ของแท่งที่เลือกโดยไม่แสดงราคา
- ส่งแท่ง เส้น กรอบ เส้นหัก และคำอธิบายให้ Gemini ตีความ HLOC พร้อมสร้างภาพตัวอย่างขาขึ้น/ขาลง โดยใช้เส้นหักอธิบายทิศทางคาดการณ์หลังเกิดแพตเทิร์น ไม่ใช้เป็นเงื่อนไขตรวจรูปแบบแท่งย้อนหลัง
- เลือก ลบ ย้อนกลับ และทำซ้ำการแก้ไข
- ซูมด้วยล้อเมาส์หรือปุ่ม +/− ได้ตั้งแต่ 20% ถึง 400% และลากกราฟในโหมดเลือกเพื่อเลื่อนดูส่วนต่าง ๆ
- ใช้ปุ่ม “พอดี” เพื่อจัดแท่งทั้งหมดให้อยู่ในมุมมอง
- บันทึกและโหลดแพตเทิร์นจาก local storage ของเบราว์เซอร์
- ให้ Gemini สรุปและปรับปรุงคำอธิบายตาม HLOC พร้อมสร้างภาพตัวอย่างขาขึ้นและขาลงอย่างละ 5 แท่งและเส้น Entry / TP / SL ยาว 5 ช่อง; ระบบสลับโมเดลและลองคำขอใหม่เมื่อผู้ให้บริการขัดข้องชั่วคราว
- สร้าง JavaScript function **detectPattern(candles)** 3 ทางเลือกจากแท่งต้นแบบ: เทียบ HLOC, รูปร่าง body/ไส้, ทิศทางเนื้อแท่ง และลำดับ Close โดยมีระดับความยืดหยุ่นต่างกัน
- แสดงผล AI เป็นสรุป HLOC และการ์ดภาพตัวอย่างขาขึ้น/ขาลง ส่วนโค้ดไม่แสดงในหน้าผลลัพธ์และส่งออกได้เมื่อเลือก logic แล้ว

โค้ดที่สร้างเป็นจุดเริ่มต้นสำหรับการศึกษา ควรตรวจสอบและทดสอบย้อนหลังด้วยตนเอง เว็บนี้ไม่แสดงสัญญาณซื้อขายและไม่ใช่คำแนะนำการลงทุน
