# Candle Pattern Lab

เว็บ dashboard แบบ standalone สำหรับวาดหรืออธิบายแพตเทิร์นแท่งเทียน แล้วให้ Gemini สร้าง JavaScript logic หลายแบบให้เลือก

## เปิดใช้งานในเครื่อง

1. ติดตั้ง Node.js 18 ขึ้นไป
2. รัน **npm install**
3. คัดลอก **.env.example** เป็น **.env** แล้วใส่ Gemini API key
4. รัน **npm start** แล้วเปิด http://localhost:3000

เครื่องมือวาด จุดปรับรูปทรง คำอธิบายแพตเทิร์น undo/redo และคลังแพตเทิร์นทำงานในเบราว์เซอร์ การสร้าง logic ด้วย AI ใช้ **GEMINI_API_KEY** ที่ฝั่ง server เท่านั้น โดยไม่ส่ง key ไปยังหน้าเว็บ เปลี่ยนโมเดลได้ด้วย **GEMINI_MODEL**

## Deploy

Deploy เป็น Node web service โดยใช้ root directory ที่ repository root, build command **npm install** และ start command **npm start** จากนั้นเพิ่ม **GEMINI_API_KEY** ใน Environment ของผู้ให้บริการ แอปจำกัดคำขอ AI ต่อ IP ในแต่ละนาที

## ฟังก์ชัน

- วาดแท่งขึ้นและแท่งลงได้สูงสุด 12 แท่ง
- ลากเส้นทั่วไป วาดเส้นหักแบบหลายจุด และวาดกรอบสี่เหลี่ยม โดยมีเส้นกำกับรวมได้สูงสุด 40 เส้น
- วาง Entry / TP / SL อย่างละหนึ่งเส้น ระบบจะแทนที่เส้นเดิมเมื่อวางระดับชนิดเดียวกันอีกครั้ง
- เลือกแล้วลากเส้น กรอบ หรือจุดหักเพื่อแก้ไข หรือลบด้วยเครื่องมือลบ
- แสดงรูปทรงแท่งโดยไม่แสดงตัวเลขราคา และลากจุดจับเพื่อแก้ Open / High / Low / Close
- ส่งแท่ง เส้น เส้นหัก กรอบ และคำอธิบายให้ Gemini สร้าง logic 3 ทางเลือก: ตามภาพ ตามคำอธิบาย และแบบยืดหยุ่น
- เลือก ลบ ย้อนกลับ และทำซ้ำการแก้ไข
- ซูมด้วยล้อเมาส์หรือปุ่ม +/− และลากกราฟในโหมดเลือกเพื่อเลื่อนดูส่วนต่าง ๆ
- ใช้ปุ่ม “พอดี” เพื่อจัดแท่งทั้งหมดให้อยู่ในมุมมอง
- บันทึกและโหลดแพตเทิร์นจาก local storage ของเบราว์เซอร์
- ให้ Gemini สร้าง JavaScript function **detectPattern(candles)**
- คัดลอกหรือดาวน์โหลดโค้ดที่ได้

โค้ดที่สร้างเป็นจุดเริ่มต้นสำหรับการศึกษา ควรตรวจสอบและทดสอบย้อนหลังด้วยตนเอง เว็บนี้ไม่แสดงสัญญาณซื้อขายและไม่ใช่คำแนะนำการลงทุน
